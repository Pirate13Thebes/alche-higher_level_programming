# Python - More Classes and Objects

This project covers more advanced OOP concepts in Python including class attributes, static methods, class methods, __str__, __repr__, and __del__.

## Files

- **0-rectangle.py** - Empty Rectangle class
- **1-rectangle.py** - Rectangle with private width and height
- **2-rectangle.py** - Rectangle with area and perimeter
- **3-rectangle.py** - Rectangle with string representation
- **4-rectangle.py** - Rectangle with eval-friendly repr
- **5-rectangle.py** - Rectangle with deletion message
- **6-rectangle.py** - Rectangle with instance counter
- **7-rectangle.py** - Rectangle with custom print symbol
- **8-rectangle.py** - Rectangle with bigger_or_equal static method
- **9-rectangle.py** - Rectangle with square class method
