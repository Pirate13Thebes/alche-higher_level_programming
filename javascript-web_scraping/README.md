# JavaScript - Web scraping

This project covers manipulating JSON data, using the `request` module and `fetch` API, and reading/writing files with the `fs` module.

## Learning Objectives

- How to manipulate JSON data
- How to use `request` and `fetch` API
- How to read and write a file using the `fs` module

## Requirements

- All files are interpreted on Ubuntu using Node.js
- All files must be executable and end with a new line
- The first line of all files must be `#!/usr/bin/node`
- Code must pass `semistandard` linting
- Use of `var` is not allowed
