# Python - Input/Output

This project covers file handling, JSON serialization/deserialization, and object persistence in Python.

## Files

- **0-read_file.py** - Reads a text file and prints it to stdout
- **1-write_file.py** - Writes a string to a text file
- **2-append_write.py** - Appends a string to a text file
- **3-to_json_string.py** - Returns JSON representation of an object
- **4-from_json_string.py** - Returns object from JSON string
- **5-save_to_json_file.py** - Saves object to a JSON file
- **6-load_from_json_file.py** - Creates object from a JSON file
- **7-add_item.py** - Adds arguments to a list saved in JSON
- **8-class_to_json.py** - Returns dictionary description of an object
- **9-student.py** - Student class with to_json method
- **10-student.py** - Student class with filtered to_json method
- **11-student.py** - Student class with reload_from_json method
- **12-pascal_triangle.py** - Pascal's triangle function
