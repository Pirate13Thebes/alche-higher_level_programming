# JavaScript - Web jQuery

This project covers DOM manipulation, CSS class manipulation, event binding, and Ajax GET requests using jQuery 3.x and vanilla JavaScript.

## Learning Objectives

- How to select HTML elements in JavaScript and with jQuery
- Differences between ID, class, and tag name selectors
- How to modify an HTML element style
- How to get and update HTML element content
- How to modify the DOM
- How to make GET and POST requests with jQuery Ajax
- How to listen/bind to DOM and user events

## Requirements

- All files are interpreted on Chrome
- Files must end with a new line
- Code must pass `semistandard *.js --global $`
- jQuery version 3.x is used
- Use of `var` is not allowed
