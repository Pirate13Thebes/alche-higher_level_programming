# Python Exceptions

This project covers exception handling in Python using try/except/finally blocks.

## Files

- **0-safe_print_list.py** - Prints x elements of a list safely
- **1-safe_print_integer.py** - Prints an integer safely using {:d}.format()
- **2-safe_print_list_integers.py** - Prints only integers from a list safely
- **3-safe_print_division.py** - Divides 2 integers and prints the result
- **4-list_division.py** - Divides two lists element by element
- **5-raise_exception.py** - Raises a TypeError
- **6-raise_exception_msg.py** - Raises a NameError with a message
