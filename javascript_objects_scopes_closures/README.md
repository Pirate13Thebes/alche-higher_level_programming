# JavaScript - Objects, Scopes and Closures

This project covers JavaScript classes, object-oriented patterns, scopes, and closures.

## Learning Objectives

- How to create an object in JavaScript
- What `this` means
- What `undefined` means
- Why variable type and scope matter
- What a closure is
- What a prototype is
- How to inherit an object from another

## Requirements

- All files are interpreted on Ubuntu 20.04 using Node.js 14.x
- All files must be executable and end with a new line
- The first line of all files must be `#!/usr/bin/node`
- Code must pass `semistandard` linting
- Use of `var` is not allowed
